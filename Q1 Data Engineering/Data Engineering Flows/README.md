## Reference Materials

Existing notes under [`reference/Azure-Data-Engineering-Notes/`](reference/Azure-Data-Engineering-Notes/) were used for pattern alignment (medallion layers, metadata-driven ADF, support runbooks). Project-specific docs in `projects/` are the **authoritative per-project flow** deliverables.

## Conventions Used Across Docs

- **Resource naming:** `{org}-{proj}-{env}-{region}-{service}-{purpose}` (e.g., `contoso-iot-prod-eus2-adf-orchestration`)
- **Medallion paths:** `abfss://{layer}@{storage}.dfs.core.windows.net/{domain}/{entity}/`
- **Environments:** `dev` → `test` → `prod` with ADF global parameters and Databricks workspace catalogs per env
